# npm-usecase

A basic Node.js project showing how to use
[`file-character-countrrr`](https://www.npmjs.com/package/file-character-countrrr).

## Run it

Install dependencies and run the example:

```bash
npm install
npm start -- Hello npm
```

Output:

```text
Text: Hello npm
Characters: 9
Characters without spaces: 8
```

If no text is provided, the example uses `Hello from my npm package!`.

## Test it

```bash
npm test
```
